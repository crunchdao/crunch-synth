# Rewards Function

Demonstrates how crunch-synth weekly rewards are computed.

## Run

```bash
pip install pandas numpy
python3 rewards_function.py          # small made-up example
python3 rewards_function.py --real   # real checkpoint data (example_data/)
```

`example_data/` holds a real leaderboard + config snapshot — see its [README](./example_data/README.md) for details.
